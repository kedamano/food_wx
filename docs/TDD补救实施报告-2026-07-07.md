## 四、解决的问题

### 4.1 编译错误修复
| 文件 | 问题 | 修复方案 |
|------|------|----------|
| RegisterTest.java:161 | varargs 类型不匹配 | 先查 User 再传入 |
| OrderServiceTest.java:214 | `var` 关键字 (Java 8) | 改为显式类型 `InOrder` |

### 4.2 运行时错误修复
| 测试 | 问题 | 修复方案 |
|------|------|----------|
| JwtUtilTest | JWT iat 秒级精度导致同秒 Token 相同 | `Thread.sleep(1100)` |
| VerifyCodeUtilTest | `verifyCode(null, *)` NPE | 在方法入口添加 null 检查 |
| UserServiceTest | mock insert 后 userId = null | `user.setUserId(100)` 模拟自增 |
| SecurityIntegrationTest | H2 URL 参数错误 | 移除 `CHARACTER SET`，使用 `-Dfile.encoding=UTF-8` |

### 4.3 环境兼容性修复
| 问题 | 修复方案 |
|------|----------|
| Maven Git Bash 启动失败 | 使用 `java -classpath` 直接运行 Launcher |
| Jest 29 + Node.js v22 不兼容 | 迁移到 Vitest 2.1.0 |
| vitest `done()` 已弃用 | 重写为 return Promise 模式 |
| vitest `done.fail()` 不存在 | 替换为 `done(new Error(...))` |
