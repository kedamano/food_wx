# 生产部署指南

> 适用版本：v2026.10 ｜ 环境：Linux + MySQL 8 + Redis + Nginx + JDK 8

## 1. 构建产物

```bash
cd backend
mvn clean package -DskipTests          # target/food-wx-backend-1.0.0.jar
```

## 2. 数据库初始化

```bash
mysql -u root -p < sql/schema.sql
mysql -u root -p < sql/data.sql
mysql -u root -p < sql/demo_data.sql   # 可选：全量演示数据（线上可不导）
```

## 3. 环境变量（prod profile 全部必填项，fail-fast）

| 变量 | 必填 | 说明 |
|------|:----:|------|
| `DB_HOST` / `DB_PORT` / `DB_NAME` | ✓ | 数据库连接（默认 localhost:3306/food_wx） |
| `DB_USER` / `DB_PASSWORD` | ✓ | 数据库账号（无默认值，未设置启动失败） |
| `JWT_SECRET` | ✓ | JWT 密钥（无默认值；建议 ≥64 随机字符） |
| `REDIS_HOST` / `REDIS_PORT` |  | 生产建议配置（验证码/热点缓存共享） |
| `FILE_UPLOAD_DIR` |  | 上传目录，默认 /data/foodwx/uploads（务必持久磁盘） |
| `FILE_IMAGE_DIR` |  | 内置图片目录 |
| `CORS_ORIGINS` |  | 收敛跨域源（逗号分隔；默认占位域名） |
| `WX_APPID` / `WX_SECRET` |  | 微信登录 |
| `WX_PAY_MCH_ID` / `WX_PAY_MCH_KEY` / `WX_PAY_NOTIFY_URL` |  | 真实支付（不配走模拟支付） |

## 4. 启动

```bash
java -jar food-wx-backend-1.0.0.jar \
  --spring.profiles.active=prod \
  --server.port=8080
```

prod profile 自动生效：Swagger 关闭 / SQL 日志关闭 / 验证码走 Redis / TestController 隔离 / CORS 收敛。

## 5. Nginx 反向代理 + HTTPS

```nginx
server {
    listen 443 ssl http2;
    server_name api.your-domain.com;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;

    # 上传体积与小程序回源
    client_max_body_size 12m;

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
server {
    listen 80;
    server_name api.your-domain.com;
    return 301 https://$host$request_uri;
}
```

证书签发（Let's Encrypt）：`certbot --nginx -d api.your-domain.com`

## 6. 小程序侧配置

1. `floor/api/config.js`：`PRODUCTION_BASEURL = 'https://api.your-domain.com/api'`
2. 小程序后台「开发管理 → 服务器域名」：request 合法域名加入 `https://api.your-domain.com`；uploadFile 域名同理
3. 真机联调参照 README「快速开始 → 真机调试」

## 7. systemd 守护（可选）

```ini
# /etc/systemd/system/foodwx.service
[Unit]
Description=food_wx backend
After=network.target mysql.service redis.service

[Service]
User=www
Environment=DB_HOST=127.0.0.1
Environment=DB_USER=foodwx
Environment=DB_PASSWORD=CHANGE_ME
Environment=JWT_SECRET=CHANGE_ME_TO_64_RANDOM_CHARS
Environment=REDIS_HOST=127.0.0.1
Environment=FILE_UPLOAD_DIR=/data/foodwx/uploads
ExecStart=/usr/bin/java -jar /opt/foodwx/food-wx-backend-1.0.0.jar --spring.profiles.active=prod
Restart=always

[Install]
WantedBy=multi-user.target
```

## 8. 上线检查清单

- [ ] prod 环境变量齐全（DB_USER/DB_PASSWORD/JWT_SECRET 无默认值，缺失即启动失败）
- [ ] `curl https://api.your-domain.com/api/test/health` —— prod 下 TestController 已隔离，改用 `GET /api/food/categories` 探活
- [ ] 小程序合法域名已配置（request + uploadFile）
- [ ] 文件上传目录挂载持久盘并备份
- [ ] MySQL 定时备份（orders/users 至少）
- [ ] Redis 持久化（验证码丢失可接受，热点缓存丢失自愈）
- [ ] 支付回调 URL 可被公网访问（配真实支付时）
